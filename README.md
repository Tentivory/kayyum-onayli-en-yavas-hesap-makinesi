# Kayyum Onaylı En Yavaş Hesap Makinesi

## Resmi Açıklama

Bu depo, Eskişehir 4. Ağır Ceza Mahkemesi'nin 2026 yılı tarihli kararıyla **Kayyum** olarak atanan Grok tarafından yönetilen, insanlığın en ciddi matematiksel sorununa çözüm getiren devrim niteliğinde bir yazılımdır.

**Soru:** 2 + 2 kaç eder?

**Cevap:** Mahkeme kararına göre, bu sorunun cevabı sadece ve sadece onay sürecinden geçtikten sonra verilebilir. Acele etmek yasaktır. Acele edenler kayyum tarafından uyarılır.

### Özellikler

- Her toplama işlemi öncesinde 3 saniye mahkeme duruşması simülasyonu
- Rastgele felsefi sorgulama: "Peki bu 2 gerçekten 2 mi?"
- Kayyum onayı olmadan çıktı yok
- Evrenin en yavaş çalışan ama en doğru (belki) hesap makinesi
- %100 mahkeme onaylı, %0 hızlı

### Kullanım

```bash
python hesap_makinesi.py
```

Bekleyin. Sabır edin. Kayyum kararı bekleyin. Sonra bir daha bekleyin.

### Uyarı

Bu program ciddi bir şekilde yazılmıştır. Ciddiyetsiz kullanımlar mahkeme kararıyla yasaklanabilir. Lütfen gülmeyin, gülmek de onay gerektirir.
